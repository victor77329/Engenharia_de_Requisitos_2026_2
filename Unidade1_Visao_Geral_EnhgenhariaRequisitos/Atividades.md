# Atividade Prática - Engenharia de Requisitos

## 1. Quem utilizará o sistema?
Os Alunos, Para consultar notas, frequência, histórico escolar e horários de aula. Professores para lançar notas, registrar faltas e consultar turmas e a Secretaria para realizar matrículas, cadastrar novos alunos, gerar relatórios e gerenciar o sistema.

## 2. Cite 3 requisitos funcionais (o que o sistema deve fazer)
O sistema deve permitir que o professor registre a frequência diária dos alunos.

O sistema deve permitir que o aluno consulte suas notas e médias finais de cada disciplina.

O sistema deve permitir que a secretaria cadastre novos alunos com informações pessoais e dados de contato.

## 3. Cite 2 requisitos não funcionais (como o sistema deve funcionar)
Desempenho: O sistema deve carregar as páginas de consulta de notas em no máximo 3 segundos.

Segurança: O acesso aos dados dos alunos deve ser restrito por meio de autenticação com senha criptografada, garantindo a privacidade conforme a LGPD.

## 4. Por que é importante levantar os requisitos antes de desenvolver um software?
É fundamental para garantir que o software atenda às reais necessidades dos usuários, evitando o desperdício de tempo e recursos com funcionalidades desnecessárias. Um bom levantamento previne retrabalho, reduz custos de desenvolvimento e alinha as expectativas entre a escola (cliente) e a equipe de desenvolvimento.
